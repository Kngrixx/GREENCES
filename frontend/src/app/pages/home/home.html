Monitoreo y ventilación inteligente

Condiciones estables para el material biológico, en todo momento.

GreenCES vigila la temperatura, la humedad ambiente y la humedad del sustrato en zonas de almacenamiento. Un ESP32 decide en tiempo real cuándo ventilar y lo indica con señales luminosas. La plataforma web guarda el historial y lo presenta en tableros claros.

Cómo decide

Reglas de control claras y verificables

Se aplican solo con el sistema ENCENDIDO. El pulsador alterna entre encendido y apagado.

Temperatura

< {{ u.tempBaja }} °C LED verde 30 %
{{ u.tempBaja }}–{{ u.tempMedia }} °C LED verde 70 %
{{ u.tempMedia }}–{{ u.tempAlta }} °C LED verde 100 % + ventilador
≥ {{ u.tempAlta }} °C LED rojo + ventilador

Histéresis: el ventilador enciende al llegar a {{ u.tempMedia }} °C y solo se apaga cuando la temperatura baja de {{ u.ventiladorApaga }} °C. Así no se prende y apaga a cada rato.

Humedades → LED blanco

  • Encendido fijo si la humedad ambiente y la del sustrato están por debajo de {{ u.humedadBaja }} %.
  • Parpadea cada 500 ms si al menos una de las dos llega a {{ u.humedadAlta }} % o más.
  • Apagado en cualquier otro caso.

Apagado: sin mediciones ni envíos; LEDs y ventilador apagados y valores en cero.
